**Harbor Lights — Spot the Difference**: a complete, original spot-the-difference game set in a seaside harbour. Two near-identical harbour scenes side by side, 3 levels × 10 differences (30 in all) with a difficulty progression — timers of 3:00, 2:30 and 2:00 — hints (3 per level), combo scoring, stars, pause/mute, level unlocks and best scores. All art is hand-drawn inline SVG and all sounds are synthesized with WebAudio; the game plays fully offline in a desktop browser from its own static files, with keyboard and mouse.

## Run it

```sh
node serve.mjs
```

Then open http://localhost:8080 in a desktop browser. Or serve the `game/` directory with any static HTTP server and open `game/index.html`.
